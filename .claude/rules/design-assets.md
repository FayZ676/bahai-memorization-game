# Generated art

`Design/` holds generators for art that ships as an asset, one folder per thing:
`AppIcon/` (the nine-pointed star, rasterised into `Assets.xcassets`) and
`StoreFrames/` (App Store screenshots).

The generator is the source, the asset is the artefact — edit the generator, never the output.
Each folder's README is the source of truth for it. Read it before changing anything there.
